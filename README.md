# 📊 Power BI Sales Analytics Dashboards

## 📌 Project Overview

This project presents two interactive **Power BI dashboards** developed to analyse and visualise sales data. The project demonstrates the use of **Exploratory Data Analysis (EDA), data transformation, business intelligence, data visualisation, and dashboard development** to generate meaningful insights from sales data.

The dashboards were developed using the **Global Bike Sales dataset**, which contains information relating to products, customers, sales, regions, dates, and other sales-related variables.

The project consists of two main dashboards:

1. **Amazon Sales EDA Dashboard**
2. **Executive Sales Dashboard**

---

## 🎯 Project Objectives

The main objectives of this project were to:

* Analyse overall sales performance.
* Identify sales trends and patterns.
* Examine product and customer performance.
* Analyse regional sales performance.
* Identify key business performance indicators.
* Transform raw sales data into meaningful visual insights.
* Develop interactive dashboards to support data-driven decision-making.

# 📈 Dashboard 1: Amazon Sales EDA Dashboard

The **Amazon Sales EDA Dashboard** was developed to provide an interactive exploration of sales data and identify important trends, patterns and relationships within the dataset.

### Key Features

* Sales performance analysis
* Product-level analysis
* Customer analysis
* Regional analysis
* Sales trend analysis
* Interactive filters and slicers
* KPI cards
* Data visualisations

### Purpose

The dashboard enables users to explore the dataset interactively and understand which products, customers and regions contribute most significantly to overall sales performance.
